## 4. 必须知道的“演示成分”

验收时不要把这些当真实功能：

| 功能 | 现状 |
|---|---|
| 学生确认 / 放弃 | 确认页的“模拟”按钮，不是学生端 |
| 学院审核 | `/demo/review` 演示台，不是学院端 |
| 登录 | 点角色即进入，无密码 |
| 数据 | 浏览器 localStorage，换电脑/清缓存就没了 |
| 通知 | 演示数据 + 本地动作触发，无推送 |
| 附件 | 占位提示，无真实文件 |
| 简历 | Mock 生成 |

## 7. 移植门槛（验收通过后）

1. 一次只搬 1~2 页；
2. 每页必须 `npm run build`（含 `vue-tsc`）通过；
3. 每页改完由你看一眼，再继续；
4. Mock 数据保留在独立文件，接口就绪后替换；
5. 不直接把 JS 文件粘进 TS 项目。
