# 学生实训室双向选拔与统筹调剂管理平台（骨架 V0.1）

软件学院实训室进组选拔流程的信息化平台。本仓库当前为**第一阶段系统骨架**：
四端路由、菜单、权限守卫、八大阶段页面结构已打通，数据使用 Mock。

## 快速开始

```bash
cd frontend && npm install && npm run dev
```

详见 `docs/DEVELOPMENT.md`。

## 后端契约

```bash
cd backend && npm install && npm run dev   # http://localhost:3000
curl http://localhost:3000/api/meta/enums
```

教师/组长接口已挂路由并做 JWT + RBAC + **阶段门禁**（写接口按阶段拒绝）；
学生端、学院端、文件接口为 **501 契约占位**，
按 `docs/INTEGRATION.md` 的替换点实现即可，前端无需改页面。

## 本机启动补充

系统未装 Node，已放一份免安装版在 `~/.local/node`：

```bash
export PATH="$HOME/.local/node/bin:$PATH"
cd frontend && npm run dev
```

骨架已通过 `npm run build` 验证。
