## 5. 关键横切能力

| 能力 | 实现方式 |
|---|---|
| 统一响应 | `Result<T>` |
| 全局异常 | `GlobalExceptionHandler` |
| 日志追踪 | `@WebLog` + AOP + Logback |
| 限流 | `@RateLimit` + Redis + AOP |
| 国际化 | `LocaleResolver` + `messages*.properties` |
| 接口文档 | SpringDoc OpenAPI 3（含 JWT SecurityScheme） |

## 6. 部署拓扑

- 前端：Nginx 静态托管 + `/api` 反向代理
- 后端：8080
- 中间件：MySQL 8.0、Redis
- 网络：docker bridge 自定义网络
