## 一、这两个告知在系统里出现在哪

不是文档摆设，是**会议页顶部可展开的横幅**，需要本人在场读完后点「同意」。

出现位置：`frontend/src/views/common/InterviewMeeting.vue:20-52`

```
面试会议页
├─ AI 数据处理告知（折叠）
│    标题：AI 数据处理告知 · <版本号>
│    正文：<INTERVIEW_AI_NOTICE>
│    系统自动追加：转写服务处理会议音频，DeepSeek 处理转写文本。你的选择独立于录制和入会。
│    按钮：同意本场 AI 处理 / 不同意 AI 处理 / 撤回
│
└─ 面试录制告知（折叠）
     标题：面试录制告知 · 版本 <版本号>
     正文：<RECORDING_NOTICE>
     系统自动追加：录像保存 <N> 天。获授权的学院负责人可因正式争议暂停清理。
     按钮：同意本场录制 / 不同意录制 / 撤回并请求停止录制
```

**所以草案里不要写「保存多少天」和「谁处理音频/文本」——这两句代码会自动追加，写进正文会重复显示。**

## 二、变量的实际作用（已核对代码）

| 变量 | 作用 | 缺失后果 |
| --- | --- | --- |
| `RECORDING_NOTICE` | 录制告知正文 | 录制功能整体关闭 |
| `RECORDING_POLICY_VERSION` | 告知版本号，显示在横幅标题 | 同上 |
| `RECORDING_RETENTION_DAYS` | 保存天数，整数 1–3650 | 同上 |
| `INTERVIEW_AI_NOTICE` | AI 处理告知正文 | AI 转写与纪要整体关闭 |
| `INTERVIEW_AI_POLICY_VERSION` | AI 告知版本号 | 同上 |

关键业务约束（`backend/services/interviewRecording.js:61`）：

```js
// 本场全部在场人员（面试官 + 学生 + 已入会旁听教师）都 ACCEPTED 才会启动录制
function authorizePending(store, interview, recording) {
  return [...requiredUsers(store, interview)].every(uid => consentFor(store, recording, uid) === 'ACCEPTED')
}
```

即：**任一人不同意，本场不录制，会议照常进行**。这一点必须写进告知，否则学生不知道拒绝的后果，同意也不构成有效同意。

## 三、草案正文

### 3.1 `RECORDING_NOTICE`（录制告知）

> 本场面试由软件学院统一组织录制音视频，用于选拔过程留痕、评分复核、争议处理与面试档案归档。录像仅存放于学院管理的对象存储私有空间，不对外公开，不用于商业用途或与选拔无关的分析；查看、下载仅限获授权的面试官、实训室组长与学院负责人，并全程记录审计日志。录制须经本场全部在场人员同意后才会启动；任一人不同意时本场不录制，会议照常进行，不影响面试成绩与录取结果。你可以随时在会议页撤回同意，撤回后本场录制立即停止。

### 3.2 `RECORDING_POLICY_VERSION`

```
v1.0
```

### 3.3 `RECORDING_RETENTION_DAYS`

```
180
```

建议 180 天（覆盖一个完整选拔周期 + 成绩申诉与复核期）。必须为 1–3650 的整数，超出会被判为无效配置，录制直接关闭。

> 权衡：过短，学期末的争议调不出录像；过长，个人信息保存义务与泄露风险同步上升。

### 3.4 `INTERVIEW_AI_NOTICE`（AI 处理告知）

> 为便于教师回顾面试内容，本场在取得录制授权并完成录像后，将对录像做中文语音转写，并依据转写文本生成结构化会议纪要。转写与纪要仅供教师评分参考，不参与自动打分，不作出录取决定，也不会依据外貌、表情或声音特征推断个人能力。纪要须经教师审核确认后才作为正式档案，AI 原始稿及修改过程一并留档，供事后追溯。你可以拒绝本场 AI 处理，拒绝不影响面试、评分与录取结果。

### 3.5 `INTERVIEW_AI_POLICY_VERSION`

```
v1.0
```

## 四、填进 `.env` 的准确写法

⚠️ **必须写成单行**。`dotenv` 不支持未加引号的多行值，正文里不要有真实换行。

```ini
RECORDING_NOTICE=本场面试由软件学院统一组织录制音视频，用于选拔过程留痕、评分复核、争议处理与面试档案归档。录像仅存放于学院管理的对象存储私有空间，不对外公开，不用于商业用途或与选拔无关的分析；查看、下载仅限获授权的面试官、实训室组长与学院负责人，并全程记录审计日志。录制须经本场全部在场人员同意后才会启动；任一人不同意时本场不录制，会议照常进行，不影响面试成绩与录取结果。你可以随时在会议页撤回同意，撤回后本场录制立即停止。
RECORDING_POLICY_VERSION=v1.0
RECORDING_RETENTION_DAYS=180

INTERVIEW_AI_NOTICE=为便于教师回顾面试内容，本场在取得录制授权并完成录像后，将对录像做中文语音转写，并依据转写文本生成结构化会议纪要。转写与纪要仅供教师评分参考，不参与自动打分，不作出录取决定，也不会依据外貌、表情或声音特征推断个人能力。纪要须经教师审核确认后才作为正式档案，AI 原始稿及修改过程一并留档，供事后追溯。你可以拒绝本场 AI 处理，拒绝不影响面试、评分与录取结果。
```

## 五、两个会影响运维的事实

### 5.1 改文案 = 已授权记录全部失效

`backend/services/interviewAi.js:21` 把告知正文纳入授权指纹：

```js
const policyKey = createHash('sha256')
  .update(JSON.stringify([notice, version, endpoint.href, sttModel, model]))
  .digest('hex')
```

**改动 notice 文案、版本号、STT 地址、STT 模型或 DeepSeek 模型中的任意一项，指纹都会变，历史授权全部作废，在场人员需重新点同意。**

推论：告知文本要在正式批次开始前定稿。调试期随便填不影响，一旦开录再改文案，会让已面完的场次失去 AI 授权。

### 5.2 拒绝录制不等于 AI 一定没有

AI 纪要以录像文件为输入。若无人拒绝、录制正常完成，才有转写与纪要；若录制失败或未启动，AI 面板会提示无可处理素材，这属预期行为，不影响教师正常评分。
