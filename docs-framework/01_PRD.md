# 01 PRD｜学生实训室进组选拔平台

> 版本：v1.0（阶段 1 定稿待确认）
> 定位：全院统一平台 · 多实训室并行 · 双向选择 · 分轮录取 · 统筹调剂

## 1. 项目背景

- **一句话定位**：面向全院的「学生实训室进组选拔」线上平台，把导师双选、分轮录取与统筹调剂的全过程搬到线上，做到规则可执行、名额可实时、结果可公示、过程可追溯。
- **目标用户**：全院在读学生、实训室导师、实训室负责人、学院教学管理人员。
- **解决的核心问题**：
  1. 原双选依赖线下表格与群通知，志愿、面试、录取、递补、调剂多轮流转，人工统计易错，名额与顺位无法实时同步。
  2. 学生跨多轮反复确认意向缺少统一入口，易出现「同一学生被多名导师重复拟录取」「名额空置无人递补」。
  3. 导师只见本室局部信息，跨室调剂与全院名额统筹缺乏数据支撑。
  4. 公示与异议无留痕，争议时无法回溯。
- **业务目标**：
  1. 3 轮录取 + 统筹调剂全流程线上跑通，一次选拔周期内完成全员入组。
  2. 名额占用与释放实时准确，从系统层面杜绝重复录取与超录。
  3. 每个环节有明确时间窗与系统兜底：逾期未确认自动视为放弃，并触发顺位递补。

## 2. 核心术语表

| 术语 | 英文 | 定义 |
|---|---|---|
| 实训室 | Lab | 学院下属实训组织单元，下辖若干导师，独立组织统一面试与录取 |
| 导师 | Mentor | 具备招录资格的教师，拥有个人招录名额 |
| 实训室负责人 | Lab Leader | 由学院管理员从导师中提拔，权限叠加在本室导师账号之上 |
| 学院管理员 | Admin | 平台最高权限，负责轮次时间窗、档案、审核、调剂与公示 |
| 意向 | Intention | 学生对某位导师的报名志愿；首轮最多 3 个、补录轮 1 个，**不分先后** |
| 统一面试 | Unified Interview | 以实训室为单位组织的单场面试，一套分数由本室导师共享使用 |
| 四维评分 | Four-Dimension Score | 学习态度、逻辑思维、编程基础、时间投入四项分数 |
| 总分 | Total Score | 四维按权重折算的合计，系统自动计算，导师可手动覆写并留痕 |
| 拟录取 | Nomination | 导师在个人名额上限内勾选的录取意向 |
| 递补名单 | Waitlist | 按总分排序的候补队列，导师可手工调整顺位并留痕 |
| 轮次 | Round | 一轮完整的「填报 → 面试 → 拟录取 → 确认」，共 3 轮 |
| 调剂 | Reallocation | 名额未满时按三级优先把未录取学生分配到有空缺的导师 |
| 公示 | Publicity | 最终名单公示 1 天，期间学生可提异议工单 |

## 3. 用户角色

| 角色 | 端侧 | 核心诉求 | 权限范围 |
|---|---|---|---|
| 学生 | 学生端 | 了解实训室与导师、填报首轮 3 个 / 补录 1 个意向、查面试安排、确认录取、提异议 | 仅本人数据；不可见任何他人录取信息 |
| 导师 | 教师端 | 查看报名学生、录四维评分、勾选拟录取、调整递补顺位 | 仅本人名下报名与拟录取；**不可见其他导师评分与录取决定** |
| 实训室负责人 | 教师端（权限叠加） | 配本室名额、组织面试排期、录本室统一面试分数、汇总本室录取 | 本室全部导师的报名、评分、拟录取、名额、递补 |
| 学院管理员 | 管理端 | 配轮次时间窗、管账号、提负责人、统筹调剂、公示与异议 | 全院数据 |

**账号与认证规则**

- 学生端、教师端**登录入口分离**；管理端独立入口。
- **账号统一由学校创建**：学生凭学号、教师凭工号，由学院管理员批量导入或单条新增，**不开放自助注册**。
- 初始密码由系统生成或管理员指定，**首次登录强制修改密码**后方可进入业务页面。
- 账号状态：启用 / 禁用；禁用账号登录提示「账号已被禁用，请联系学院管理员」。
- 负责人不新建账号：学院管理员从本室导师中提拔，权限叠加；同一实训室仅 1 名负责人。
- 登录态：JWT + Redis 黑名单，支持登出即失效。

### 4.3 八阶段时间轴与系统空档期

| 阶段 | 线上化程度 | 时间窗（示例，全部可配） | 系统状态 |
|---|---|---|---|
| ① 集中宣讲 | 线下 + 线上展示 | 10-28 19:00 单点 | 只读 |
| ② 实训室开放日 | 线下 + 线上展示 | 10-29 ~ 10-30 | 只读 |
| ③ 意向填报 | 全线上 | 11-02 08:00–12:00 | 可写 |
| ④ 导师初选与面试 | 全线上（排期 + 录分） | 11-02 12:00 ~ 11-03 17:00 | 可写 |
| ⑤ 拟录取与确认 | 全线上 | 名单提交期 → 批次签发 → 学生确认期，共三段 | 分段可写 |
| ⑥ 分轮补录 | 全线上 | 11-04 12:00 ~ 11-05 17:00 | 循环 ③④⑤ |
| ⑦ 统筹调剂 | 全线上 | 11-06 08:00–12:00 | 可写 |
| ⑧ 公示与入组 | 全线上 | 公示 1 天 | 只读 + 异议 |

**空档期规则（阶段之间）**

1. 任一阶段结束后到下一阶段开始前，系统一律**只读**。
2. 只读期学生仍可查看本人填报、面试安排、录取结果；不可提交、不可修改。
3. 只读期导师与负责人不可新增、修改、删除任何业务数据。
4. 所有时间判断以**服务端时间**为准，客户端时间不参与判定。
5. 窗口关闭后写接口统一返回 `400004 不在有效时间窗内`，不做「宽容几分钟」。
6. **不提供个人补交**：任何角色都不能为单个学生单独开窗。
7. **系统故障延长**：仅学院管理员可发起，对所有参与者统一生效，必须公告 + 写 `operation_log`。

### 4.4 角色 × 八阶段站位表

| 角色 | ① 宣讲 | ② 开放日 | ③ 填报 | ④ 面试 | ⑤ 确认 | ⑥ 补录 | ⑦ 调剂 | ⑧ 公示 |
|---|---|---|---|---|---|---|---|---|
| 学生 | 查看公告 | 查看开放日安排 | 填报首轮 ≤3 / 补录 1 + 调剂意愿 | 查看面试安排、参加面试 | 接受 / 拒绝（待确认中心） | 未录取者重报 | 查看调剂结果、可放弃 | 查看本人结果、提异议 |
| 导师 | 查看实训室档案 | 线下接待 | **名单全盲** | 查看本室分数、勾选拟录取、排递补 | 查看录取状态 | 补录再选、免面试直录 | **池内抢录，先到先得直接生效** | 查看本人名单 |
| 负责人 | 查看本室名额 | 维护开放日信息 | 填报截止后查看本室填报数（仅聚合） | 排期、录分、汇总本室名单 | 汇总提交 | 统筹本室补录 | 本室内部调剂 | 查看本室名单 |
| 学院管理员 | 发布公告、审定名额 | 全院统筹 | 配置时间窗、监控进度 | 监督进度 | 监督确认 | 公布剩余名额 | 跨室 / 座谈安置 | 发起公示、处理异议、确认入组 |

**四条读表结论**

1. 阶段③导师**全盲**：填报截止前看不到任何名单、数量、提交时间，截止后才可见。
2. 阶段④评分权在**负责人**：全室统一一套分数，导师的初选权体现在勾选拟录取与排递补顺位。
3. 阶段⑥剩余名额**由系统算出**：等于 `quota - quota_used`，不允许管理员手工填写。
4. 阶段③盲选门禁**对导师与负责人同时生效**：填报窗口内负责人只能看到本室聚合数量且一律为 0，不得下钻到名单；填报截止后才可见本室聚合数量。

## 5. 页面与元素拆解

### 5.1 公共端（未登录可访问）

#### 页面：实训室列表 `/labs`

- 顶部栏：平台名称 + `[学生登录]`、`[教师登录]` 两个入口按钮。
- 筛选区：实训室名称关键词搜索框、所属系部下拉、招录状态下拉（招录中 / 已满 / 未开放）、`[重置]`。
- 卡片列表（默认 12 条/页）：每卡展示实训室名称、负责人、导师数、总名额、`已录 X / 剩余 Y`（剩余 0 时数字标红）、`[查看详情]`。
- 空态：无数据时展示「暂无实训室信息」。
- 分页器：上一页 / 页码 / 下一页，显示总条数。

#### 页面：实训室详情 `/labs/:id`

- 头部：实训室名称、负责人、总名额、剩余名额（>0 绿色，=0 红色「已满」）。
- 简介区：实训室简介、研究方向标签、设备与环境。
- 导师列表：头像、姓名、职称、研究方向、个人名额 `已录 X / 剩余 Y`、`[查看导师]`。
- 培养安排：培养周期、每周投入、培养方式（AI+PBL 项目实训）。
- 考核要求：考核节点与形式。
- 开放日安排：日期、时段、地点、注意事项；开放日结束后该区显示「开放日已结束」灰色文案。
- 底部操作栏：主按钮 `[我要报名]`；未登录点击跳转学生登录并带回跳地址；不在填报时间窗内时置灰，文案分别为 `[填报未开始]` / `[填报已截止]`。

#### 页面：导师详情 `/mentors/:id`

- 基本信息：头像、姓名、职称、所属实训室、研究方向、在研项目。
- 名额区：个人名额、已录、剩余；名额为 0 时标注「已满」。
- `[返回实训室]` 次按钮。

#### 页面：公告栏 `/notices`、`/notices/:id`

- 列表：标题、类型标签（宣讲 / 开放日 / 公示 / 通知）、发布时间、`[详情]`。
- 详情：正文富文本、附件下载；公示类公告带 `[查看公示名单]`。
- 分页器：10 条/页。

### 5.2 学生端

#### 页面：学生登录 `/student/login`

- 登录：学号输入框、密码、`[登录]`、`[忘记密码]`（点击弹提示「请联系学院管理员重置密码」，不开放自助找回）。
- 无「注册」入口，页面底部灰字提示「账号由学校统一创建，如无账号请联系学院管理员」。
- 校验：学号不存在 → 「账号不存在，请联系学院管理员」；账号被禁用 → 「账号已被禁用，请联系学院管理员」；密码错误 → 「学号或密码错误」。
- 首登改密：使用初始密码登录成功后强制跳转「修改密码」页，未改密前不可访问其他业务页面。

#### 页面：学生工作台 `/student`

- 轮次横幅：`第 N 轮 · 填报中` + 剩余时长倒计时（`剩余 2 天 3 小时`）。
- 待办卡片：待填报 / 待参加面试 / 待确认录取，各自带 `[去处理]`。
- 我的填报摘要：3 张意向卡片（导师 + 实训室）+ 两个调剂意愿标签。
- 通知列表：最近 5 条，未读带红点，`[查看全部]`。

#### 页面：我的档案 `/student/archive`

- 分步表单共五段：基本信息、学业、技能与经历、时间投入、个人陈述。
- 基本信息：学号、姓名、学院、专业、年级，全部只读，来自账号。
- 学业区：班级、GPA、专业排名、英语等级；后三项选填。
- 技能区：编程语言（标签多选，必填至少 1 项）、工具链（标签多选）、项目经历（文本域，必填）。
- 经历区：竞赛、科研、实习三个文本域，均选填。
- 时间投入区：每周可投入小时（数字 1–40，必填）、可投入时段（文本，必填，如「工作日 19:00–22:00」）、其他组织任职（选填）。
- 个人陈述区：文本域，**300–800 字**，实时字数计数；下方灰字提示「所有导师看到的是同一份陈述，不能针对不同导师写不同版本」。
- 底部：`[保存草稿]`（次）、`[保存并去填报]`（主）。
- 校验：必填项缺失时保存仍成功，但「意向填报」页的 `[提交填报]` 置灰，提示「你还有 X 项档案必填未完成，[去完善]」。

#### 页面：意向填报 `/student/intention`

- 提示条：当前轮次、填报截止时间、倒计时。
- 意向区：3 个卡位。
  - 已选卡：导师姓名、所属实训室、研究方向、名额剩余、`[更换]`、`[移除]`。
  - 空位卡：`[+ 添加意向]`，点击打开「选择导师弹窗」。
- 调剂意愿区：三个开关 —— 「服从实训室内部调剂」「服从全院跨实训室调剂」「同意全院导师在调剂池查看我的完整档案」，开关下方灰色小字说明含义；第三个仅在勾选跨室调剂时可用。
- 底部操作栏：`[保存草稿]`（次）、`[提交填报]`（主）。
  - 意向数 = 0 时 `[提交填报]` 置灰，提示「至少选择 1 个意向」。
  - 档案必填未完成时 `[提交填报]` 置灰，提示「请先完善档案」。`[去完善]` 跳转档案页。

#### 页面：异议处理 `/admin/disputes`

- 表格列：工单号、学生、类型、提交时间、状态、`[处理]`。
- 处理弹窗：处理结果下拉（维持原结果 / 调整录取 / 退回重审）、处理意见文本域、`[提交]`。
- 提交后推送站内通知给学生，状态更新为「已回复」。

#### 页面：全院录取总览 `/admin/results`

- Tab：按实训室 / 按导师 / 按学生。
- 统计图：各实训室名额饱和度、导师录取率。
- 表格 + `[导出 Excel]`。
- 行操作 `[调整]`：弹窗选择动作（手动确认 / 取消通过 / 改派 / 置放弃），改派时下拉选择目标导师，**原因必填**；提交写操作日志，并在学生端推送通知。

## 6. 非功能需求

- **性能**：单轮峰值 2000 学生并发填报，接口 P95 < 500ms；名单导出 5000 行内 < 10s。
- **安全**：密码 BCrypt 存储；JWT + Redis 黑名单；所有查询与写操作在服务端做**归属校验**，禁止仅凭前端传参；学号、姓名、手机号在非本人视图中脱敏。
- **一致性**：名额占用与拟录取走**条件更新**，防止超录与重复录取；关键状态变更全部落操作日志。
- **兼容性**：Chrome / Edge 最近两个大版本；学生端支持 375px 以上响应式。
- **可用性**：确认、放弃、调剂、删除等不可逆操作必须二次确认；所有倒计时以服务端时间为准。

## 7. 边界与不做的事

- **MVP 红线**：
  1. 第 1 步集中宣讲、第 2 步实训室开放日**仅线上展示信息**，不做预约、签到。
  2. 3 轮录取 + 统筹调剂必须完整闭环。
  3. 名额、分数、顺位、录取结果全链路可追溯。
- **明确不做（MVP）**：
  1. 在线笔试与自动判分（V2）。
  2. 学生线上自选剩余名额（V2）。
  3. 对接学院统一认证 SSO（一期由学院管理员统一创建账号替代）。
  4. 短信 / 邮件通知（一期仅站内通知）。
  5. 面试视频、录音存档。
  6. 移动端 App 与小程序。
